# SIPAD — Gestão Documental

Apresentação institucional do **Sistema Integrado de Plano de Classificação e Tabela de Temporalidade de Documentos**, criado para apoiar a gestão documental e arquivística em ambiente universitário.

## Problema atendido

Planos de classificação, prazos de guarda e destinações documentais exigem consulta consistente e padronizada. O SIPAD organiza essas informações em uma aplicação web, reduzindo consultas manuais e apoiando decisões de classificação e temporalidade.

## Solução

- Consulta estruturada ao plano de classificação
- Apoio à tabela de temporalidade e destinação
- Organização de códigos e descritores documentais
- Interface web para uso institucional
- Persistência estruturada em SQLite, JSON e CSV
- Execução em Linux por servidor WSGI

## Arquitetura

A aplicação foi desenvolvida em Python com organização em camadas, backend centralizado e interface baseada em templates HTML. O modelo separa regras de negócio, persistência e apresentação para facilitar manutenção e evolução.
